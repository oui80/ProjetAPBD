# Vision

L’application permet à un petit groupe d’utilisateurs de centraliser simplement leurs activités sportives.

## Besoin principal

Un utilisateur doit pouvoir :

1. créer librement son compte ;
2. importer un ou plusieurs fichiers FIT ;
3. retrouver ses activités dans un historique clair ;
4. consulter les informations principales d’une activité.

## Philosophie

- Petit projet, architecture simple.
- Fiabilité avant sophistication.
- Interface sobre et facile à comprendre.
- Aucune donnée sportive inventée.
- Analyses ajoutées progressivement après le MVP.

## Utilisateurs

Environ 20 utilisateurs pratiquant la course, le trail ou le cyclisme.

Les fonctions sociales, le coaching et les classements sont **HORS MVP**.
