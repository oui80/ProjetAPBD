# Critères d’acceptation du MVP

## Compte

- Un visiteur peut créer librement un compte.
- Il peut se connecter et se déconnecter.
- Il peut connecter et déconnecter son compte Intervals.icu.
- Une erreur ne crée pas de compte incomplet ou en double.

## Import FIT

- Un utilisateur peut importer un ou plusieurs fichiers valides.
- Un fichier invalide affiche une erreur claire.
- Un doublon exact n’est pas créé deux fois.
- Un fichier en erreur ne bloque pas les autres fichiers du lot.

## Historique

- L’utilisateur voit uniquement ses activités.
- Il peut rechercher, filtrer par sport et trier par date.
- Chaque carte affiche seulement les métriques disponibles.
- L’état vide explique comment importer une première activité.

## Synchronisation Intervals.icu

- Le bouton récupère uniquement les activités nouvelles ou modifiées.
- Le fichier original est téléchargé lorsqu’il est disponible.
- Un FIT généré peut être utilisé lorsque l’original n’est pas un FIT.
- Le bilan distingue les imports réussis, doublons, activités ignorées et erreurs.

## Détail

- Un clic ouvre l’activité.
- Les informations principales sont lisibles sur ordinateur et mobile.
- Une donnée absente n’est pas inventée.
- Le retour conserve le contexte de l’historique.

## Interface

- Fond blanc, texte noir, accents bleu clair et rouge.
- Navigation au clavier et contrastes lisibles.
- Aucun défilement horizontal sur mobile.
