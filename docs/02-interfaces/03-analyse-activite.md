# Page 3 — Détail et analyses

## MVP

Au MVP, cette page reste simple. Elle affiche :

- retour vers l’historique ;
- nom, date et sport ;
- source de l’activité ;
- distance, durée, allure ou vitesse ;
- dénivelé, fréquence cardiaque et puissance si disponibles.

Aucune analyse avancée n’est nécessaire pour valider le MVP.

## Évolution après le MVP

La page accueillera des tuiles indépendantes. Chaque tuile correspondra à une analyse, par exemple :

- graphique d’allure ;
- fréquence cardiaque ;
- puissance ;
- cadence ;
- carte GPS ;
- tours et intervalles ;
- analyse de montée.

Une tuile doit pouvoir être ajoutée ou retirée sans modifier les autres. Si ses données sont absentes, elle affiche une courte explication ou n’est pas proposée.

## Direction visuelle

Les graphiques futurs utilisent le bleu clair pour la série principale et le rouge pour la série secondaire. Le texte reste noir sur fond blanc.

## Critères d’acceptation du MVP

- Les informations principales sont lisibles sur desktop et mobile.
- Les champs absents ne sont pas inventés.
- Le retour vers l’historique conserve les filtres précédents.
