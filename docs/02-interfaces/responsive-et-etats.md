# Responsive et états

## Responsive

- Une colonne sur mobile.
- Liste compacte pour l’historique et tuiles en plusieurs colonnes sur écran large.
- Aucun défilement horizontal.
- Boutons suffisamment grands pour un usage tactile.
- Formulaires et textes utilisables avec un zoom à 200 %.

## États communs

Chaque page prévoit seulement les états nécessaires :

- chargement ;
- contenu disponible ;
- contenu vide ;
- erreur avec action pour réessayer.

Pour un import, afficher également le traitement en cours et le résultat de chaque fichier.

## Accessibilité

- Contraste lisible.
- Navigation au clavier.
- Focus visible.
- Libellés explicites.
- Une couleur n’est jamais la seule information disponible.
- Les zones tactiles font au moins 44 × 44 px.
