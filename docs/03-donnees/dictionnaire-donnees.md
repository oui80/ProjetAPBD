# Données principales

## Activité

| Donnée | Format conceptuel |
|---|---|
| Nom | Texte |
| Sport | Course, trail, vélo ou autre |
| Date | Date et heure |
| Durée | Secondes |
| Distance | Mètres |
| Allure | Secondes par kilomètre |
| Vitesse | Mètres par seconde |
| Dénivelé | Mètres |
| Fréquence cardiaque | Battements par minute |
| Puissance | Watts |
| Appareils | Métadonnées réellement présentes dans le FIT |

## Échantillon

Un échantillon peut contenir un instant, une distance, une position GPS, une altitude, une vitesse, une fréquence cardiaque, une cadence et une puissance.

Tous les champs sportifs sont optionnels. Une valeur absente n’est jamais remplacée par zéro.

## Réglage utilisateur

La fréquence cardiaque maximale est optionnelle, propre à chaque utilisateur et comprise entre 100 et 240 bpm. Elle sert uniquement au calcul de charge estimée.
